## Latest confirmed changes

- Every map has a few real hidden natural openings, very hard to find unaided. No free environmental clues, preferred walls, route counters or recognizable wrong-branch guarantees. Remove the prior 10% map-existence gate, single exit and fake/no-exit compass bearings.
- Explorer may buy a much more expensive **single-use** Merchant compass pointing approximately toward the nearest real opening. One use per item, not an unrequested one-purchase-per-player limit.
- Workers can save unused pickaxes until expiry and mine immediately when an Explorer completes discovery, including round one if prepared and fast enough. No next-round activation delay remains.
- User asked what the Guard rule was, not to approve a new refund policy. On checking timing, the earlier paid-Guard timeout gap was overstated: explicit current-round authorization at a≥10 implies subsequent timeout d+110≥120, after delivery 30. Enforce current-round offers/kit/action; future drafts cannot auto-activate; reject stale offers. Ordinary disconnect preserves accepted delivery. No new exception/refund policy is needed or adopted.
